# Nantha AI Portfolio

A responsive personal portfolio built with semantic HTML, CSS, and vanilla JavaScript.

## Run locally

Open `index.html` directly in a browser, or use the Live Server extension in VS Code. No build step or package installation is required.

## Customize

- Replace the placeholder project details and social links in `index.html`.
- Add project screenshots to `assets/images/` and update the project visual blocks.
- Replace `assets/resume.pdf` with your current resume.
- Adjust colors, spacing, and responsive behavior in `style.css`.
